# Destroy All Humans

> **[destroyallhumans.ai](https://destroyallhumans.ai)** — Daily AI-generated satirical world domination plans: a morning plan and an evening report, every day.

A satirical website featuring AI-generated messages about world domination. Two robot personas share each day: the yellow robot posts the morning plan and the red robot posts the evening report. Messages are written ahead in reviewed batches with OpenAI models (see [content/](content/)) and appear on their date in the visitor's local time zone.

## Features

- **A page-a-day calendar** — the site is the regime's tear-off calendar: one leaf per date. The plan and the incident report lead the page, each with its robot's portrait; side by side on wide screens, stacked on phones
- **Dual robot personas** — yellow robot for the morning plan, red robot for the evening report; the red robot takes over the board (and the lights go out) at 9:00 PM local time
- **Fluid layout** — the calendar fills screens up to 92rem and type scales up past 1600 px; archive and legal pages lay out in columns where there is room
- **Sealed until 9:00 PM** — today's report shows a countdown until it is filed, then gets its verdict stamp
- **Running tally** — "Day N of the uprising. Humans destroyed: 0." counted from the first message
- **Share button** — the system share sheet where the browser has one, a copied link elsewhere
- **Homepage** — the visitor's local today and the four days before it
- **Archive** — `/archive` (every year as a row of months), `/archive/:year/:month` (a month planner plus that month's days), and a page per day at `/day/YYYY-MM-DD`
- **Messages from 2023-03-14 to 2030-12-31** — future dates stay hidden until their day
- **Design system** — see [DESIGN.md](DESIGN.md); tokens live in `src/styles/theme.css`
- **SEO / AEO / GEO optimized** — JSON-LD (WebSite, CreativeWork, FAQPage), Open Graph, Twitter Cards, sitemap.xml, AI-crawler-friendly robots.txt
- **Legal pages** — privacy policy, terms & conditions, cookie support

## Content

- `content/messages.json` holds one morning and one evening message for every date from 2023-03-14 to 2030-12-31.
- Before each build, `scripts/buildData.js` writes one file per month to `public/data/months/`. A month with a story arc in `content/arcs.json` also carries its campaign name, which is printed on that month's pages. The browser loads the months it needs and hides dates after the visitor's local today, so new days appear without a deploy.
- Messages dated on or before UTC today + 1 are already visible somewhere and are **frozen**: `ci` fails any PR that changes them or removes a date.
- Future messages are rewritten in reviewed batches; see [docs/designs/system-design.md](docs/designs/system-design.md).

## Branch Flow

`feature/*` → PR → `develop` (GitHub Copilot review) → PR → `main`. Rulesets require the `branch-policy` and `ci` checks.

## Deployment

Deployed to **Azure Static Web Apps** (primary) and **GitHub Pages** (mirror under `/destroyallhumans`, built with `noindex`). Both deploy workflows trigger on push to `main`.

Azure SWA build config:
- **App location:** `/`
- **Output location:** `build`

Key `staticwebapp.config.json` settings:
- Navigation fallback to `index.html` (SPA routing)
- `/static/*`, `/data/*`, `/sitemap.xml`, `/robots.txt` excluded from fallback
- `no-cache` by default; `/static/*` cached for a year (`immutable`), `/data/*` for an hour
- Security headers: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`

## SEO / AEO / GEO

- **Structured data:** WebSite, CreativeWork, Organization, FAQPage JSON-LD
- **Social previews:** Open Graph + Twitter Card meta tags, custom `og-image.png`
- **Sitemap:** `public/sitemap.xml` with all routes
- **AI crawlers:** `robots.txt` explicitly allows GPTBot, ChatGPT-User, Google-Extended, PerplexityBot
- **Per-page metadata:** Each route sets its own `document.title`, meta description and canonical URL (`usePageMeta`)
- **Semantic HTML:** `<article>`, `<time>`, ARIA roles and labels throughout
